# Handover Analysis in 5G Networks <sub><sup>5G 네트워크의 핸드오버 분석</sup></sub>
## Purpose <sub><sup>목적</sup></sub>
This project analyses the performance of a 5G network when multiple User Equipment (UE) Devices simultaneously download data. The study evaluates how network performance changes with increasing numbers of UEs and with varying traffic loads, determined by packet size and transmission interval. We implemented file senders and receivers for three protocols, TCP/IP (Transmission Control Protocol/Internet Protocol), UDP (User Datagram Protocol), and QUIC (Quick UDP Internet Connections), for the simulation.

본 프로젝트는 여러 사용자 장비(UE)가 동시에 데이터를 다운로드할 때 5G 네트워크의 성능을 분석합니다. 이 연구는 UE 장비 수 증가 및 패킷 크기와 전송 간격으로 결정되는 다양한 트래픽 부하에 따라 네트워크 성능이 어떻게 변화하는지 평가합니다. 시뮬레이션을 위해 TCP/IP(전송 제어 프로토콜/인터넷 프로토콜), UDP(사용자 데이터그램 프로토콜) 및 QUIC(Quick UDP Internet Connections)의 세 가지 프로토콜에 대한 파일 송수신기를 구현했습니다.
